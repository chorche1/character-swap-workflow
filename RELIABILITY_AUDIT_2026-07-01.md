### `src/character_swap/reengineer.py:409` — Analyst plan missing one scene idx silently misaligns every later scene's prompt/dialogue and drops the last scene
*Found by: runner-reengineer*

analyze_scenes deliberately tolerates a partial plan (`if i in by_idx` — the guard proves the omitted/duplicated-idx case is anticipated) and returns a list SHORTER than `frames`, but its only consumer, runner_reengineer._analyze line 478, pairs it POSITIONALLY: `for i, ((a, b), frame, plan) in enumerate(zip(spans, frames, plans))`. A shorter `plans` list is compacted, so every scene at or after the missing idx receives the NEXT scene's motion prompt + spoken dialogue, and zip-truncation drops the final span/frame from `scene_entries` entirely. The corrupt entries are then persisted to plan.json (line 491), so `_load_cached_plan` on any crash-resume re-serves the misaligned plan without re-billing — the one path that could have healed it. Nothing fails loudly: the run proceeds to the gate with N-1 scenes and off-by-one dialogue. The fix-shaped invariant (return None unless len(plans) == len(frames), falling back to fallback_plans) is exactly what the `or None` tail already implies was intended.

**Failure scenario:** A 12-scene reference video; the forced tool_choice Claude call returns scenes idx 0-3 and 5-11 (omits 4 — e.g. it merged two similar shots, common on long scene lists). analyze_scenes returns 11 plans; _analyze zips them against 12 spans/frames: scene 4's frame gets scene 5's dialogue, scene 5 gets scene 6's, ..., and scene 11 (the video's closing line/CTA) is silently absent from scene_entries and every character's final. The user approves images at the gate (the thumbnails look right — only the attached dialogue is shifted, easy to miss across 11 rows), pays for 11 Kling clips per character, and ships finals where every character speaks each line over the wrong footage and the ending is missing. status lands 'done'; plan.json caches the corruption for resumes.

**Verification evidence:** src/character_swap/reengineer.py:316-337 (tool schema: no minItems, unbounded idx); src/character_swap/reengineer.py:405-409 (compacting return `[by_idx[i] for i in range(len(frames)) if i in by_idx] or None`); src/character_swap/runner_reengineer.py:478 (positional `zip(spans, frames, plans)`, plan.idx ignored, entry idx from enumerate); src/character_swap/runner_reengineer.py:453-463 (fallback only on `plans is None`); src/character_swap/runner_reengineer.py:493-495 (misaligned scene_entries persisted to plan.json); src/character_swap/runner_reengineer.py:318-343 (_load_cached_plan checks only scene-PNG existence — resume re-serves corruption); src/character_swap/reengineer.py:468-483 (fallback_plans emits exactly one plan per span — the violated invariant); tests/ grep: no test feeds a partial scenes array or asserts len(plans)==len(frames)
